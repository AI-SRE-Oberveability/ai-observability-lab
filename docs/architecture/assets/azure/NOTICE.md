# Microsoft Azure architecture icons

These selected, unchanged SVG files come from Microsoft's official Azure architecture icon pack V24. Their use here is limited to architecture diagrams/documentation. Microsoft retains the icon rights; the repository source licence does not relicense them. Follow the [official terms and usage guidance](https://learn.microsoft.com/en-us/azure/architecture/icons/). Do not distort, recolor or repurpose them as application branding. Source archive paths and SHA256 receipts are in provenance.json.

# Official-icon architecture

Open azure-governance.drawio in diagrams.net or a compatible draw.io editor. All containers, labels, connectors and six official Azure icon images are individually editable. The SVG/PNG are standalone previews; they are not a flattened source file. Icons are embedded, so the diagram needs no remote icon URLs. Source/rights receipts are under assets/azure.

This is the current planned AKS + Citadel/APIM target, not deployment evidence. The model route uses AKS Workload ID to APIM, then a separate APIM managed identity. Terraform delivery remains gated/disabled. Optional existing resources are unverified references. See governance-plan.md for acceptance cases and the phase sequence.
